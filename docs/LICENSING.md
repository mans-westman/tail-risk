# Licence and attribution

This project is licensed under the **[MIT License](../LICENSE)** (`Copyright (c) 2026 Mans Westman`),
declared in `pyproject.toml` with PEP 639 metadata (`license = "MIT"`, `license-files = ["LICENSE"]`).

This page records the rationale for choosing MIT over Apache-2.0, the declared licences of the
direct dependencies, and the boundary between code rights and market-data rights. It is practical
engineering context, not legal advice.

## Why MIT was chosen

Between the two standard permissive options (MIT and Apache-2.0):

| Point | MIT (chosen) | Apache-2.0 |
|---|---|---|
| Length and reading effort | ~170 words, one paragraph | ~10 KB of numbered terms |
| Patent licence | Silent | Explicit grant from contributors, with a termination clause if a licensee sues over patents |
| Trademark | Silent | Explicitly grants no trademark rights |
| Notice obligations | Keep the copyright and permission notice | Keep the licence, and any `NOTICE` file if one exists; state changes made to modified files |
| Warranty and liability | Disclaimed | Disclaimed |
| GPL compatibility | Compatible in both directions | Compatible with GPLv3; **not** with GPLv2-only |
| Typical fit | Small research code, maximum reuse | Code an organisation may adopt, where an explicit patent grant reduces review friction |

For a compact solo research toolkit with no vendored third-party code and no patent claims, MIT
provides maximum compatibility (including with every direct dependency below) and minimal reading
overhead for reviewers and users. No `NOTICE` file is required.

## Third-party material and attribution

No third-party source code is vendored. The one model that does not import the toolkit,
`examples/bring_your_model/ewma_gaussian.py`, is project-written and says so.

| Package | Role | Licence declared by the installed distribution |
|---|---|---|
| NumPy | arrays, quantiles | BSD-3-Clause (with bundled 0BSD/MIT/Zlib/CC0-1.0 components) |
| SciPy | distributions, optimisation | BSD-3-Clause |
| pandas | panel and artifact tables | BSD-3-Clause |
| `arch` | GARCH-t maximum likelihood (`baselines`) | NCSA, a BSD-style permissive licence |
| Matplotlib | optional figures (`plots`) | PSF-style Matplotlib licence |
| JAX, Optax | optional MLP training (`neural`) | Apache-2.0 |
| pytest | tests (`dev`) | MIT |
| `pandas_market_calendars` | optional calendar cross-check (`data`) | MIT |

Every direct dependency is permissive; none is copyleft. The table is the licence each
installed distribution declares, not a legal determination for redistribution, and it does not
cover transitive dependencies. Methods and their sources are cited in
[docs/METHODS.md](METHODS.md).

**Data is separate from code.** Market data is not redistributed: `data/` is ignored, example
CSVs are generated by repository code, and the synthetic series come from the toolkit's own
generator. The MIT code licence grants no rights to any vendor feed a user ingests.
